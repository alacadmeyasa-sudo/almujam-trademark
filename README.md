| الملف | الوصف |
|------|-------|

## 🚀 طريقة الاستيراد إلى ووردبريس / How to import

### المتطلبات
- موقع ووردبريس مع إضافة **Elementor** (المجانية تكفي؛ بعض الودجت مثل الأكورديون متاحة في النسخة المجانية).
- يُفضّل تفعيل اتجاه **RTL** للموقع (الإعدادات > عام، أو من سمة عربية).

### الخطوات
1. ادخل لوحة تحكم ووردبريس ← **Templates / القوالب ← Saved Templates**.
2. اضغط زر **Import Templates / استيراد القوالب** في الأعلى.
3. اختر الملف `elementor-template.json` وارفعه.
4. افتح القالب المستورد، ثم **Edit with Elementor**.
5. عدّل أي عنصر بالنقر عليه (العناوين، النصوص، الأزرار، الأيقونات، الأسئلة الشائعة...).
6. اضغط **Publish / نشر** ثم اربط الصفحة بقائمة الموقع أو اجعلها الصفحة الرئيسية.

> بديل: من أي صفحة جديدة، افتح Elementor ← أيقونة المجلد (Add Template) ← تبويب **My Templates** ← استورد الملف ← Insert.

## ✏️ ما الذي يمكن تعديله في Elementor؟ / Editable elements
كل عنصر في الصفحة قابل للتحرير بصريًا:
- **العناوين والنصوص** — النقر المباشر وتغيير الخط واللون والحجم والمحاذاة.
- **الأزرار** — النص، اللون، والرابط (الاتصال/الواتساب).
- **الأيقونات والبطاقات** (icon-box) — تغيير الأيقونة، العنوان، الوصف، الألوان.
- **قوائم المزايا** (icon-list).
- **الأسئلة الشائعة** (accordion) — إضافة/حذف/تعديل الأسئلة.
- **الأقسام والأعمدة** — الخلفيات، التباعد، الحدود، والتجاوب مع الجوال.

## ☎️ تحديث رقم التواصل / Changing the phone number
الرقم الحالي `966541447701` يظهر في:
- زر **«اتصل الآن»** ← الرابط `tel:+966541447701`
- زر **«واتساب»** ← الرابط `https://wa.me/966541447701`
- قسم الـ Hero، قسم الدعوة لاتخاذ إجراء (CTA)، والفوتر.

لتغييره: إمّا تعديل الأزرار/النصوص مباشرة في Elementor، أو تعديل `PHONE_RAW` و`PHONE_DISPLAY`
في `build_template.py` وإعادة التشغيل:

```bash
python3 build_template.py
```
